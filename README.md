# Tic-Tac-Toe Game

This is a simple, fully functional browser-based Tic-Tac-Toe game built from scratch using only HTML, CSS, and JavaScript.

## Project Structure
The project is kept minimal with the following main files:
* `index.html`: Contains the layout and structure of the game board and UI.
* `style.css`: Handles the visual styling, grid layouts, and responsive design.
* `script.js`: Contains the game logic, event listeners, player turns, and win/draw conditions.

## How to Run and Play
1. Download or clone this repository to your local machine.
2. Navigate to the project folder.
3. Double-click the `index.html` file to open it in any modern web browser (Chrome, Firefox, Safari, Edge).
4. Player X goes first by clicking any empty square on the 3x3 grid.
5. Players alternate turns until someone gets 3 marks in a row (horizontally, vertically, or diagonally), or the board fills up resulting in a draw.
6. Click the "Restart Game" button to reset the board and play again.
